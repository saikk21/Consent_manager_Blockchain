# Phase C.4 Iframe Integration Guide

## Embed

```html
<iframe
  src="https://sammati.example.com/widget/hosted?session_token=<SESSION_TOKEN>"
  title="Sammati Consent"
  style="width:100%;border:0;"
  referrerpolicy="strict-origin-when-cross-origin"
></iframe>
```

## Parent window listener

```js
window.addEventListener("message", (event) => {
  if (event.origin !== "https://sammati.example.com") return;
  const msg = event.data;
  if (msg?.version !== "1.0") return;
  if (msg.event === "widget.resized") {
    iframe.style.height = `${msg.payload.height}px`;
  }
});
```

## Security requirements

- Session token must be generated by backend API.
- Do not generate or mutate legal text in parent app.
- Only accept postMessages from known Sammati origin.
- Keep iframe `referrerpolicy` enabled to support parent-origin runtime validation.
